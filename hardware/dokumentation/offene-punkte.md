# Offene Punkte — was nicht belegt ist, wer es klärt, was daran hängt

Stand: **17.10.2026** (Erstfassung). Jeder Punkt trägt eine Kennung `OP-nn`, auf die die anderen Dokumente verweisen. Erledigte Punkte werden **nicht gelöscht**, sondern mit Datum und Beleg auf „erledigt“ gesetzt
(damit nachvollziehbar bleibt, was einmal offen war). Fragen **an den Nutzer** stehen zuerst.

Schwere: **A** = kann die Funktion der gebauten Platine verhindern oder eine Bestellung falsch machen; **B** = Entwurfsentscheid mit Folge für Qualität oder Vorgabe; **C** = Lücke in Beleg, Werkzeug oder Dokumentation.
